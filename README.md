# Fundación Shakira

Sitio web oficial de la **Fundación Shakira** — Educación y esperanza para niños y jóvenes.

## 🌐 Estructura del proyecto

```
Shakira-Fundacion/
├── index.html          # Página de inicio
├── about.html          # Sobre nosotros
├── programs.html       # Programas
├── donate.html         # Página de donaciones
├── contact.html        # Contacto
├── css/
│   └── styles.css      # Estilos principales
├── js/
│   └── main.js         # JavaScript (menú móvil y formularios)
└── README.md
```

## ✨ Características

- Diseño moderno y responsivo
- Navegación completa entre páginas
- Secciones de impacto, programas, donaciones y contacto
- Menú adaptable a dispositivos móviles
- Formularios de demostración

## 🚀 Cómo ver el sitio

1. Clona el repositorio o descarga los archivos
2. Abre `index.html` en tu navegador
3. O activa GitHub Pages en la configuración del repositorio
